### 一、analysis_report（最佳 Epoch 68，连续值信号）

**核心指标：**
| 指标 | 数值 |
|------|------|
| 测试样本数 | 1000 |
| 输入 SNR 均值 | -9.41 dB |
| 输出 SNR 均值 | 4.14 dB |
| SNR 提升均值 | +13.55 dB |
| SNR 提升 > 0 占比 | 100% |
| MSE 均值 | 0.009935 |
| 相关系数均值 | 0.7916 |
| 相关系数 > 0.9 | 15.5% |
| 相关系数 < 0.7 | 21.6% |

**发现：**
1. SNR 提升稳定，100% 正提升
2. 相关系数偏低，21.6% 样本 < 0.7，波形形态还原不足
3. 样本间性能差异大，输出 SNR 标准差 (2.44) > 输入 SNR 标准差 (1.48)
4. 低输入 SNR 样本表现明显更差

**改进建议：**
- **高优先级**：增大 `peak_correlation_loss` 权重或引入波形相似性损失（DTW）
- **高优先级**：对低 SNR 样本做专项训练，增加高噪声比例采样
- **中优先级**：分层训练减少样本间方差，分析训练集信号多样性
- **中优先级**：增大 early stopping patience，当前 epoch 68/500 收敛偏早
- **低优先级**：增加 UNet 下采样次数（2→3）或加入更多 attention 层

### 二、error_report（最佳 Epoch 100，BPSK 二进制脉冲信号）

**核心指标：**
| 指标 | 数值 |
|------|------|
| 评估样本数 | 100 |
| 输入 SNR 均值 | -4.29 dB |
| 输出 SNR 均值 | 70.47 dB |
| 极性反转（样本级） | 12/100 (12%) |
| 极性反转（脉冲级） | 12/4511 (0.27%) |
| 总检测脉冲数 | 4511 |

**发现：**
1. 输出 SNR 极高 (70.47 dB)，噪声几乎完全移除
2. 12 个极性反转中，11 个发生在信号前 500 点（边界效应）
3. 第一个脉冲幅度衰减（±1.0 → ±0.2），同样是 UNet 边界效应
4. BPSK 场景下极性反转 = 比特错误，不可接受

**改进建议：**
- **高优先级**：对输入信号做镜像 padding 或周期性延拓，消除边界效应
- **高优先级**：训练时增大极性惩罚权重，推理时对首尾部单独做极性校验
- **中优先级**：对信号首尾段增加训练权重

### 三、training_log（训练过程分析）

**关键数据：**
| Epoch | Train Loss | Val Loss | SNR Imp |
|-------|-----------|----------|---------|
| 1 | 5.43 | 3.48 | - |
| 10 | 2.55 | 2.27 | 12.81 |
| 50 | 2.15 | 2.14 | 14.25 |
| 68 | 2.13 | 1.85 | - |
| 90 | 2.13 | 1.87 | 14.30 |
| 98 | 2.10 | 2.08 | - |

**发现：**
1. Train Loss > Val Loss（异常），dropout=0.1 部分解释，可能验证集更简单
2. Epoch 68 后 val loss 停滞甚至回升，轻微过拟合
3. SNR 提升从 epoch 50 到 90 仅增 0.05 dB，接近饱和
4. CosineAnnealing 从 2e-4 → 1.07e-4，衰减速度合理

**改进建议：**
- **高优先级**：检查训练/验证集划分是否有偏
- **中优先级**：增大 dropout_rate 到 0.2，添加 weight_decay 正则化
- **中优先级**：增大 patience 到 30+，给模型更多探索时间
- **低优先级**：当前模型容量可能不足以进一步提升 SNR

### 总结优先级排序

1. 解决边界效应（镜像 padding）√
2. 增大极性惩罚权重√
3. 增加波形形态约束（DTW / 相关系数损失）
4. 低 SNR 样本专项训练
5. 检查数据集划分，添加正则化
6. 增大模型容量
