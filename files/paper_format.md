# 《通信技术》投稿格式要求

> 来源：`通信技术模板(1).docx`

---

## 页面设置

| 参数 | 值 |
|------|-----|
| 纸张 | A4（21.0 × 29.7 cm） |
| 页边距 | 上 2.2 cm，下 2.2 cm，左 2.0 cm，右 2.0 cm |
| 分栏 | 双栏 |

---

## 中文部分

| 元素 | 字体 | 字号 | 加粗 | 备注 |
|------|------|------|:---:|------|
| 论文标题 | 黑体 | 2 号（22pt） | ✅ | |
| 作者 | 宋体 | 小 4 号（12pt） | — | 不超过 6 行 |
| 作者单位 | 宋体 | 小 5 号（9pt） | — | |
| 摘要 | 楷体 | 5 号（10.5pt） | ✅ | 200 字左右，不出现"本文" |
| 关键词 | 楷体 | 5 号 | ✅ | 4~6 个 |
| 中图分类号等 | 宋体 | 5 号 | — | |
| 一级标题（1、2、3…） | 黑体 | 4 号（14pt） | ✅ | |
| 二级标题（1.1、1.2…） | 黑体 | 5 号（10.5pt） | ✅ | |
| 正文 | 宋体 | 5 号（10.5pt） | — | |
| 图/表标题 | 宋体 | 小 5 号（9pt） | — | |
| 参考文献 | 宋体 | 小 5 号（9pt） | — | 至少 10 篇 |
| 参考文献标号 | 宋体 | 小 5 号 | ✅ | |

---

## 英文部分

| 元素 | 字体 | 字号 | 加粗 |
|------|------|------|:---:|
| 英文标题 | Times New Roman | 3 号（16pt） | ✅ |
| 英文作者 | Times New Roman | 小 4 号（12pt） | — |
| 英文单位 | Times New Roman | 小 5 号（9pt） | — |
| Abstract | Times New Roman | 5 号（10.5pt） | ✅ |
| Keywords | Times New Roman | 5 号（10.5pt） | ✅ |

---

## 其他要求

| 项目 | 要求 |
|------|------|
| 公式 | MathType 编辑，Word 自带公式编辑器也可，居中，编号右对齐 |
| 图片 | 黑白色调（印刷限制），推荐 Visio 绘图，图中文字 6 号宋体 |
| 图片中数值 | 带单位，格式如"功率/dBm" |
| 表格 | 三线表 |
| 参考文献 | 正文中按顺序上标标注，至少 10 篇 |
| 首页页脚 | 收稿日期、基金项目等 |
| "本文" | 摘要中不得出现 |
| 术语缩写 | 首次出现写全称（英文全称，缩写）|
